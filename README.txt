v23 템플릿 수정 방향
- 사용자가 제공한 찌라시 레퍼런스의 초대형 제목, 상하 반전 색면, 우측 세로 간판, 하단 대문구, 중앙 폭발표식, 세로 표식, 입체 타원 배지 구조를 다시 반영했습니다.
- 처음 다섯 템플릿은 레퍼런스의 특징을 직접 옮기되, 같은 내용을 복제하지 않고 편집 가능한 글자 영역 구조로 재설계했습니다.
- 사진 좌측 기사판은 사용자가 만든 v18.1 예시처럼 사진·폭발 배지·큰 제목·검정 안내 띠·기사판·전화번호가 한 판으로 이어지도록 다듬었습니다.
- 뒤쪽 템플릿은 기존 v22의 장점을 유지하면서 조선 계열 글꼴, 더 강한 제목 대비, 단색 외곽선과 입체 타원으로 찌라시 밀도를 높였습니다.
- 둥근 카드가 반복되지 않도록 직각 띠, 무테 글자, 타원, 폭발표식, 세로판을 섞었습니다.
- 색상은 고정하지 않고 현재 주색·보조색·강조색과 흰색·검은색 사용 설정을 따릅니다.

- 모바일과 터치 장치에서는 슬라이더 손잡이를 직접 잡아야 값이 바뀝니다. 트랙을 잘못 눌러도 값이 이동하지 않습니다.
- v21의 중앙정렬, 좁은 기본 그리드 간격, 영역별 클리핑, 역할 슬롯, 라이트 모드 버튼, 390px 반응형을 유지했습니다.

v24.1 자동 줄바꿈 수정
- 제목·기관 안내·강조·주의 문구는 영역 폭에 따라 자동 줄바꿈합니다.
- 속보 표찰, 입덕률 100.4%, 전화번호는 한 줄 유지합니다.
- 가로 폭 배율이 두 번 보정되어 줄바꿈 폭이 비정상적으로 넓어지던 문제를 수정했습니다.
- 기존 저장 데이터의 기본 예시 문구도 자동으로 새 줄바꿈 규칙으로 보정됩니다.


v25 변경 사항
- 모든 문장은 자동 줄바꿈 가능. 자동 조판은 한 줄을 우선하되 좁고 짧은 영역에서는 줄바꿈으로 글자를 키움.
- 속보, 입덕률 100.4%, 전화번호 예시는 입력창에서 한 줄로 제공.
- 사진 핸들 크기 조절은 원본 비율 고정, contain 렌더링으로 크롭 없음.
- 터치 장치에서는 슬라이더 손잡이를 잡아 실제로 움직여야 값 변경. 트랙 탭은 무시.
- 수치 조절 UI를 이름/−/수치/+/복귀 한 줄 + 짧은 슬라이더 구조로 재설계.
- 편집 패널을 2열 중심으로 정리하고 UI 글자 크기와 버튼 높이를 축소.

v26 변경 사항
- 도구 탭을 동일 높이 그리드로 고정해 오른쪽 탭으로 갈수록 내려가 보이던 현상을 제거했습니다.
- 창 폭에 따라 탭을 5열, 3열, 2열로 자동 재배치하며 가로 스크롤 없이 패널 안에 유지합니다.
- 배경·재단, 영역, 요소·사진, 문장 꾸미기의 수치 컨트롤을 가용 폭에 따라 2열 또는 1열로 전환합니다.
- 모든 수치 컨트롤을 옵션명 / 감소 / 직접 입력 / 증가 / 복귀 한 줄과 짧은 슬라이더 한 줄로 고정했습니다.
- 수동 조정 초기화, 영역 편집 버튼, 색상 버튼 등이 패널 밖으로 넘치거나 다른 버튼과 겹치지 않도록 폭과 줄바꿈 규칙을 통일했습니다.
- 390px, 980px, 1440px 화면에서 문서 전체 가로 넘침이 발생하지 않도록 검사했습니다.
- 첫 다섯 템플릿의 큰 틀은 유지하면서 제목·속보·기사·수치·전화번호의 크기 대비를 확대하고, 색면과 정보 띠를 서로 맞물리게 재설계했습니다.
- 첫 다섯 템플릿에도 뒤쪽 템플릿과 동일한 밀도, 정렬선, 좁은 기본 간격, 역할별 글꼴 규칙을 적용했습니다.

v26.2 변경 사항
- 템플릿 탭 최상단에 주색·보조색 1·보조색 2 컬러칩을 한 줄로 압축 배치했습니다.
- 컬러칩은 색상만 보여 주며, 누르면 같은 팔레트 영역 바로 아래에 기존 상세 컬러피커가 열립니다.
- 연한 배경 혼합률, 흰색·검은색 사용 여부, 보조색 1·2 사용 여부를 두 번째 한 줄에 모았습니다. 좁은 화면에서는 겹치지 않도록 단계적으로 줄바꿈합니다.
- 템플릿 목록의 첫 카드에 ‘직접 만들기’를 추가했습니다. 누르면 현재 주색의 단색 배경만 남기고 문장·영역·요소를 비운 대지에서 시작합니다.
- 앱 최초 화면은 직접 만들기가 아니라 기존 1번 레이아웃 템플릿으로 열립니다.

[v26.3 화면 모드]
- 앱은 화이트 모드로 시작합니다.
- 실행취소 버튼 바로 왼쪽의 달/해 아이콘으로 화이트·다크 모드를 전환합니다.
- 화이트 모드에서는 모든 조작 버튼을 흰색 표면으로 통일하고, 선택 상태는 검은 면 대신 테두리와 링으로 표시합니다.

[v26.4 유니코드 문자 사이 연출]
- /, ·, ★, ♥, ■, • 프리셋마다 `단어 사이`와 `글자 사이` 버전을 제공합니다.
- 글자 사이 모드는 `이/렇/게`처럼 공백을 제외한 각 글자 사이에 기호를 넣습니다.
- `직접 기호`에서는 유니코드 표에서 기호를 고른 뒤 `단어 사이` 또는 `글자 사이`를 선택할 수 있습니다.
- 기존 저장 작업의 직접 기호는 이전 동작과 동일하게 `단어 사이`로 불러옵니다.


[v26.5 영역 클리핑과 텍스트 회피]
- 사진·요소에 `사진·요소 피해서 배치`가 켜져 있어도 특정 글자 영역으로 클리핑하면 그 요소는 해당 영역의 문장 흐름에만 영향을 줍니다.
- 클리핑된 사진·요소 때문에 다른 영역의 문장이 밀리거나 줄바꿈·폭·높이가 바뀌지 않습니다.
- 회피 여백과 효과가 있어도 장애물 범위는 클리핑 영역 바깥으로 확장되지 않습니다.
- 영역에 클리핑하지 않은 사진·요소는 기존처럼 겹치는 모든 글자 영역의 흐름에 영향을 줍니다.

v26.6 변경 사항
- 선택 문장 꾸미기의 긴 접이식 블록을 탭형 편집기로 통합했습니다.
- 탭: 간격, 기호, 효과, 글자색, 선택 색, 선택 기호, 선택 배경.
- 탭을 전환하면 해당 기능의 설명이 편집기 상단에 표시됩니다.
- 문장 입력창에서 선택한 범위에만 유니코드 기호를 적용할 수 있습니다.
- 선택 범위 유니코드는 단어 사이/글자 사이를 각각 지원하며 직접 기호와 유니코드 찾기도 지원합니다.
- 적용된 선택 색, 선택 기호, 선택 배경은 시작/끝 글자 번호를 직접 수정할 수 있습니다.
- 적용 항목을 누르면 문장 입력창에서 해당 범위를 다시 선택합니다.
- 선택 범위 적용 버튼의 글자와 배경 대비를 화이트/다크 모드에서 모두 수정했습니다.

v26.7 변경 사항
- 사진을 확대해 대지 바깥으로 이동할 때 기존처럼 거의 전부를 대지 안에 묶어 두지 않습니다.
- 사진 전체 면적의 최소 5%만 대지와 겹치면 좌우·상하로 더 자유롭게 이동할 수 있습니다.
- 사진 핸들 정비율 확대·축소와 직접 위치 입력에도 같은 경계 규칙을 적용합니다.
- 사진이 매우 커서 5% 겹침이 물리적으로 불가능한 경우에는 대지와 만들 수 있는 최대 교차 면적을 유지합니다.
- 사진 렌더링은 계속 contain 방식과 원본 비율을 사용하며 크롭하지 않습니다.

[v26.8 기호 난입 순서]
- 기호 난입의 @, *, ●, /, ₩이 고정 순환하지 않고 텍스트마다 무작위 순서로 섞입니다.
- 같은 문장이 화면을 다시 그릴 때마다 기호가 계속 바뀌지 않도록 텍스트별 시드를 사용합니다.
- 같은 기호가 바로 연속해서 들어가는 경우는 피합니다.


[v26.9 문장 길이 대응 자동 조판]
- 템플릿의 자동 상태 문장은 입력창에서 내용을 바꾸는 즉시 현재 영역 안에서 다시 맞춰집니다.
- 문장 편집만으로는 수동 고정으로 바뀌지 않으며, 폰트·크기·간격·위치·영역 등을 직접 조절한 순간부터 해당 문장만 수동 고정됩니다.
- 자동 조판은 글자 크기를 영역 밀도에 맞게 최대한 키운 뒤, 넘칠 때 글자 폭 → 자간 → 행간 → 자동 줄바꿈 순으로 조정합니다.
- 자동 글자 폭은 70% 아래로 줄지 않으며, 템플릿 영역과 역할은 문장 내용이 달라져도 유지됩니다.
- 자동 상태의 장식 선택은 문장을 타이핑할 때마다 임의로 바뀌지 않도록 문장 ID 기준으로 고정됩니다.

v27 변경 사항
- 문장 카드의 위/아래/삭제 버튼을 가로 한 줄로 압축하고 각 버튼 이름을 아이콘 위에 표시합니다.
- 삭제 버튼은 버튼 근처의 확인 팝업에서 한 번 더 확인해야 실행됩니다.
- 작업 문서(문장, 템플릿, 영역, 사진, 요소, 색상, 테마)를 IndexedDB에 자동 저장하여 새로고침 후 복원합니다.
- 자동 문장은 편집 시 같은 영역 안의 글자 크기/폭/자간/행간을 다시 맞추되 영역 배치는 자동 배치 버튼을 눌렀을 때만 바뀝니다.
- 자동 조판의 최소 행간을 높이고 세로 압축 대신 글자 크기를 조절하여 행끼리 겹치는 현상을 줄였습니다.
- 미리보기에서 영역을 선택하면 그 영역의 문장이 가장 위에 그려집니다.
- 미리보기 바깥 화면의 배경색을 미리보기 상단에서 선택할 수 있습니다.


v27.1 미리보기 바탕·색 배치
- 템플릿 색상 설정 줄 오른쪽에 `색 배치 섞기` 버튼을 추가했습니다. 컬러칩의 실제 색값은 유지하고 템플릿 안에서 주색·보조색 1·보조색 2가 맡는 위치만 무작위로 바뀝니다.
- 꺼 둔 보조색은 섞기 대상에서 제외되며, 흰색·검은색 사용 설정은 그대로 유지됩니다.
- 미리보기 바탕을 흰색, 검은색, 검은 투명배경, 흰 투명배경, 투명배경 중에서 고를 수 있습니다.
- 현재 표시 모드는 `미리보기 바탕` 옆 아이콘으로 보이며 아이콘을 누르면 바로 아래에 선택 메뉴가 열립니다.
- 선택한 미리보기 바탕 모드와 색 배치 순서는 자동 저장되어 새로고침 뒤에도 유지됩니다.
