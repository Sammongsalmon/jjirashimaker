기존 저장소의 같은 파일을 덮어쓴 뒤 강력 새로고침하세요.
- Windows: Ctrl + Shift + R
- macOS: Command + Shift + R

v14 핵심 수정
- 사용자가 보낸 찌라시 디자인 레퍼런스를 반영한 15개 템플릿과 수달 예시 문구, 자동 문장 역할 분석·자동 조판을 포함합니다.
- 영역 사이 여백 슬라이더가 드래그 중에도 캔버스에 즉시 반영됩니다.
- 수동으로 이동하거나 크기를 바꾼 영역도 수동 오프셋을 유지한 채 공통 여백 값이 적용됩니다.
- 선택 영역의 ‘원래 위치’와 ‘전체 위치 복귀’를 누르면 현재 여백 값은 유지하면서 템플릿 기준 위치로 돌아갑니다.
- 기본 여백 축소량은 32px이며, 0px은 템플릿 원본 간격입니다.
- 슬라이더 트랙, 직접 입력, −/+, 원상복귀가 같은 값을 공유하고 실행취소·재실행에 기록됩니다.

디자인 방향
- 큰 제목 1개, 중간 강조 1~2개, 작은 기관 문구·부작용·전화번호를 서로 다른 크기로 배치합니다.
- 모든 칸을 둥근 카드로 만들지 않고 직각 색면, 원형 도장, 폭발 배지, 세로 라벨과 사진 자리를 선택적으로 사용합니다.
- 템플릿 색상은 현재 주색·보조색·강조색을 따라갑니다.
- 그림자는 번짐 없는 단색이며 입체 효과는 별도 그림자 없이 단색 두께 면만 그립니다.

유지되는 기능
- 실행취소/재실행 및 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y
- 모든 수치의 슬라이더·직접 입력·−/+·원상복귀
- 문장 자동 정리, 문장 드래그 자리 교환, 영역 내부 위치 제한
- PC 더블클릭 / 모바일 길게 누르기로 영역·요소 이동·회전·크기 조절
- 영역 안 전폭 띠, 사진·도형 회피 여백, PNG/JPG 저장

KoPub 폰트
assets/fonts 폴더의 기존 KoPub OTF 파일을 그대로 사용합니다. 이 ZIP에는 폰트 바이너리를 포함하지 않습니다.
