설치

2. assets/fonts 폴더와 사용자 사진·폰트 파일은 그대로 유지합니다.

v23 템플릿 수정 방향
- 사용자가 제공한 찌라시 레퍼런스의 초대형 제목, 상하 반전 색면, 우측 세로 간판, 하단 대문구, 중앙 폭발표식, 세로 표식, 입체 타원 배지 구조를 다시 반영했습니다.
- 처음 다섯 템플릿은 레퍼런스의 특징을 직접 옮기되, 같은 내용을 복제하지 않고 편집 가능한 글자 영역 구조로 재설계했습니다.
- 사진 좌측 기사판은 사용자가 만든 v18.1 예시처럼 사진·폭발 배지·큰 제목·검정 안내 띠·기사판·전화번호가 한 판으로 이어지도록 다듬었습니다.
- 뒤쪽 템플릿은 기존 v22의 장점을 유지하면서 조선 계열 글꼴, 더 강한 제목 대비, 단색 외곽선과 입체 타원으로 찌라시 밀도를 높였습니다.
- 둥근 카드가 반복되지 않도록 직각 띠, 무테 글자, 타원, 폭발표식, 세로판을 섞었습니다.
- 색상은 고정하지 않고 현재 주색·보조색·강조색과 흰색·검은색 사용 설정을 따릅니다.

[v24 변경]
- 기본 본문 글꼴을 KoPub 돋움으로 복원했습니다.
- 큰 제목/속보/연락처에는 조선로고체, 조선굵은고딕, KoPub 바탕을 역할에 따라 사용합니다.
- 첫 5개 템플릿을 대형 타이포, 세로 표찰, 폭발표식, 타원 배지 중심으로 재설계했습니다.
- 선택 글자 배경은 텍스트 선택 범위를 보존해 미리보기/저장 결과에 적용됩니다.
- 모바일과 터치 장치에서는 슬라이더 손잡이를 직접 잡아야 값이 바뀝니다. 트랙을 잘못 눌러도 값이 이동하지 않습니다.
- v21의 중앙정렬, 좁은 기본 그리드 간격, 영역별 클리핑, 역할 슬롯, 라이트 모드 버튼, 390px 반응형을 유지했습니다.

v24.1 자동 줄바꿈 수정
- 제목·기관 안내·강조·주의 문구는 영역 폭에 따라 자동 줄바꿈합니다.
- 속보 표찰, 입덕률 100.4%, 전화번호는 한 줄 유지합니다.
- 가로 폭 배율이 두 번 보정되어 줄바꿈 폭이 비정상적으로 넓어지던 문제를 수정했습니다.
- 기존 저장 데이터의 기본 예시 문구도 자동으로 새 줄바꿈 규칙으로 보정됩니다.


v25 변경 사항
- 모든 문장은 자동 줄바꿈 가능. 자동 조판은 한 줄을 우선하되 좁고 짧은 영역에서는 줄바꿈으로 글자를 키움.
- 속보, 입덕률 100.4%, 전화번호 예시는 입력창에서 한 줄로 제공.
- 사진 핸들 크기 조절은 원본 비율 고정, contain 렌더링으로 크롭 없음.
- 터치 장치에서는 슬라이더 손잡이를 잡아 실제로 움직여야 값 변경. 트랙 탭은 무시.
- 수치 조절 UI를 이름/−/수치/+/복귀 한 줄 + 짧은 슬라이더 구조로 재설계.
- 편집 패널을 2열 중심으로 정리하고 UI 글자 크기와 버튼 높이를 축소.

v26 변경 사항
- 도구 탭을 동일 높이 그리드로 고정해 오른쪽 탭으로 갈수록 내려가 보이던 현상을 제거했습니다.
- 창 폭에 따라 탭을 5열, 3열, 2열로 자동 재배치하며 가로 스크롤 없이 패널 안에 유지합니다.
- 배경·재단, 영역, 요소·사진, 문장 꾸미기의 수치 컨트롤을 가용 폭에 따라 2열 또는 1열로 전환합니다.
- 모든 수치 컨트롤을 옵션명 / 감소 / 직접 입력 / 증가 / 복귀 한 줄과 짧은 슬라이더 한 줄로 고정했습니다.
- 수동 조정 초기화, 영역 편집 버튼, 색상 버튼 등이 패널 밖으로 넘치거나 다른 버튼과 겹치지 않도록 폭과 줄바꿈 규칙을 통일했습니다.
- 390px, 980px, 1440px 화면에서 문서 전체 가로 넘침이 발생하지 않도록 검사했습니다.
- 첫 다섯 템플릿의 큰 틀은 유지하면서 제목·속보·기사·수치·전화번호의 크기 대비를 확대하고, 색면과 정보 띠를 서로 맞물리게 재설계했습니다.
- 첫 다섯 템플릿에도 뒤쪽 템플릿과 동일한 밀도, 정렬선, 좁은 기본 간격, 역할별 글꼴 규칙을 적용했습니다.

v26.2 변경 사항
- 템플릿 탭 최상단에 주색·보조색 1·보조색 2 컬러칩을 한 줄로 압축 배치했습니다.
- 컬러칩은 색상만 보여 주며, 누르면 같은 팔레트 영역 바로 아래에 기존 상세 컬러피커가 열립니다.
- 연한 배경 혼합률, 흰색·검은색 사용 여부, 보조색 1·2 사용 여부를 두 번째 한 줄에 모았습니다. 좁은 화면에서는 겹치지 않도록 단계적으로 줄바꿈합니다.
- 템플릿 목록의 첫 카드에 ‘직접 만들기’를 추가했습니다. 누르면 현재 주색의 단색 배경만 남기고 문장·영역·요소를 비운 대지에서 시작합니다.
- 앱 최초 화면은 직접 만들기가 아니라 기존 1번 레이아웃 템플릿으로 열립니다.
