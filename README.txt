v16 핵심 변경

1. 템플릿과 자동 조판
- 제공된 찌라시 굿즈 레퍼런스의 정보 밀도, 큰 제목과 작은 보조 문구의 급격한 크기 대비, 붙는 색면, 전화번호 띠, 세로 라벨, 비대칭 칸 분할을 반영한 15개 템플릿입니다.
- 가로 템플릿을 단순 회전하지 않고 각 템플릿별 세로 배치를 별도로 제공합니다.
- 문장 역할·길이·줄바꿈·영역 점유율을 계산해 영역을 고르고, 글자 크기·행간·자간·효과를 자동으로 맞춥니다.
- 텍스트가 넘치면 영역 비율을 소폭 조정하되 전체 레이아웃의 바깥 여백과 내부 간격 규칙을 유지합니다.
- 글자는 영역 안에서 세로 중앙 정렬되며, 가로 위치는 문단의 왼쪽·가운데·오른쪽 정렬을 따릅니다.
- 큰 제목은 선택적으로 인접 영역의 5% 미만까지 돌출할 수 있습니다.

2. 여백과 영역
- 대지의 상·하·좌·우 바깥 여백은 같은 값으로 맞춥니다.
- 가로·세로 내부 간격은 각각 설정하며 바깥 여백보다 좁게 유지할 수 있습니다.
- 템플릿 규칙상 붙어야 하는 칸은 0px까지 맞닿을 수 있습니다.
- ‘여백 다시 맞춤’은 수동 이동 전 템플릿 비율과 현재 여백값으로 영역을 재계산합니다.
- ‘원래 위치’와 ‘전체 위치’로 선택 영역 또는 모든 영역을 되돌릴 수 있습니다.
- ‘영역 보기’를 켜면 미리보기에 실제 글자 경계와 영역 이름이 표시됩니다.

3. 문장 꾸미기와 효과
- 문장 꾸미기 변경이 미리보기와 PNG/JPG 출력에 같은 렌더러로 반영됩니다.
- 효과는 외곽선·평면 그림자·빈 그림자·단색 입체를 여러 개 동시에 켤 수 있습니다.
- 그림자는 번짐과 그라데이션이 없는 단색 실루엣이며, 입체 효과는 별도 그림자 없이 단색 두께만 쌓습니다.
- 자동 흑백 글자색은 배경색뿐 아니라 활성 효과 색과의 최소 대비까지 계산합니다.
- 선택한 글자 범위에 색상과 배경 장식을 적용할 수 있습니다.
- 범위 배경: 사각형, 글자별 원, 긴 타원, 하트, 뾰족 말풍선.
- 범위 배경은 영역·사진·요소보다 위, 글자보다 아래에 렌더되며 줄바꿈마다 나뉩니다.
- 프리텐다드 Variable을 선택했을 때만 글자 굵기 슬라이더와 직접 입력이 나타납니다.

4. 색상
- 보조색 1·2를 각각 사용/안 함으로 고를 수 있습니다.
- 주색 하나만 써도 주색+흰색+검은색, 주색+흰색, 주색+검은색 조합으로 자동 배분합니다.
- 주색을 흰색에 얼마나 섞어 연한 배경으로 만들지 설정할 수 있습니다.
- 모든 색상 칸은 누른 위치 바로 아래에 동일한 커스텀 컬러피커를 엽니다.

5. 사진과 요소
- 사진의 투명 여백을 업로드 즉시 잘라내고 실제 알파 픽셀만 삽입합니다.
- 선택 판정, 그림자·효과, 글자 회피 여백도 실제 불투명 픽셀을 기준으로 계산합니다.
- 사각형, 원, 하트, 별, 뾰족 말풍선, 띠, 삼각형, 구름, 사진을 지원합니다.
- 요소·사진을 선택한 글자 영역에 클리핑할 수 있습니다.
- 요소·사진 탭에서는 글자 클릭을 무시해 요소만 선택합니다.

6. 선택과 조작
- 문장을 다른 영역으로 끌면 해당 영역의 문장 묶음 전체가 대상 영역의 문장 묶음과 교환됩니다.
- 선택된 문장을 다시 더블클릭하거나 길게 누르면 글자 영역 안에서만 위치·크기를 조절할 수 있습니다.
- 영역과 요소는 데스크톱 더블클릭, 모바일 길게 누르기로 이동·회전·크기 조절 핸들을 엽니다.
- 미리보기 확대·축소·화면 맞춤을 지원합니다.

7. 대지와 화면
- 전단 180×100mm, A6, A5, 카드, 정사각 프리셋과 사용자 지정 mm 입력을 제공합니다.
- 가로/세로 전환과 비율 변화 뒤에도 현재 여백·자동 조판 규칙으로 레이아웃을 다시 계산합니다.
- 라이트 모드와 다크 모드를 지원합니다.
- 모바일에서는 미리보기가 상단에 나오며 가로 넘침 없이 편집 패널을 한 열로 재배치합니다.

8. 수치 입력과 기록
- 연속 수치는 슬라이더, 직접 입력, −/+, 화살표 복귀를 함께 제공합니다.
- 숫자를 지우는 중의 빈 값, -, ., 0. 같은 입력 상태를 허용하고 Enter/포커스 해제 때 확정하며 Escape로 취소합니다.
- 슬라이더 채움과 손잡이가 같은 min/max/value를 사용해 같은 방향으로 움직입니다.
- 실행취소·재실행과 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y를 지원합니다.

Pretendard Variable 설치
이 교체 ZIP에는 사용자가 제공한 폰트 바이너리를 포함하지 않습니다. 아래 둘 중 하나를 assets/fonts에 둡니다.
- assets/fonts/PretendardVariable.woff2 (권장)
- assets/fonts/PretendardVariable.ttf

Codespaces에서 사용자가 올린 Pretendard-1.3.9.zip을 풀려면:

mkdir -p assets/fonts
unzip -j -o Pretendard-1.3.9.zip "web/variable/woff2/PretendardVariable.woff2" -d assets/fonts

KoPub 폰트
기존 assets/fonts의 KoPub OTF 파일은 그대로 사용합니다. 이 교체 ZIP에는 KoPub 폰트도 포함하지 않습니다.
