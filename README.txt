3. 배포 화면에서 강력 새로고침합니다.
   - Windows: Ctrl + Shift + R
   - macOS: Command + Shift + R

v20 핵심 변경

1. 15개 템플릿 전면 재정렬
- 사용자가 제공한 찌라시 레퍼런스의 특징을 다시 기준으로 삼았습니다.
- 큰 제목, 속보 표찰, 기관 안내, 핵심 본문, 강조 문구, 수치, 연락처, 주의 문구 사이의 위계를 더 크게 벌렸습니다.
- 같은 행에 놓인 칸은 위·아래 기준선과 높이를 맞추고, 같은 열의 좌우선도 반복해서 사용합니다.
- 모든 템플릿의 영역 묶음을 대지 중앙에 맞추고 상·하·좌·우 외곽 여백을 동일하게 정규화합니다.
- 기존에 아래쪽이 비거나 왼쪽 위로 치우치던 템플릿도 전체 영역이 대지의 약 92%를 사용하도록 다시 맞춥니다.
- 의미 없이 모든 내용을 카드에 넣지 않고, 무테 타이포형·세로 표찰형·전폭 연락처형·삼단 광고형·사진 기사형 등을 분리했습니다.
- 띠가 아닌 정보칸에는 필요한 만큼만 둥근 모서리를 사용하고, 전화번호나 기관 안내처럼 띠인 부분은 직선형을 유지합니다.
- 가로형 15종과 세로형 대응 레이아웃을 각각 별도 그리드로 제공합니다.

2. 기본 문구 줄바꿈 규칙
- 기본 예시 중 핵심 목록인 ‘배 위 조개 개봉 완료…’ 문장만 항목별 줄바꿈을 유지합니다.
- 제목, 기관 안내, 강조 문구, 수치, 연락처, 주의 문구에는 임의 줄바꿈을 넣지 않습니다.
- 핵심 목록을 제외한 자동 문장은 한 줄을 우선 유지하며, 영역에 맞출 때 글자 폭과 높이를 먼저 조정합니다.

3. 더 꽉 차는 자동 글자 크기
- 자동 조판은 영역 안에서 가능한 가장 큰 폰트 크기를 이진 탐색으로 찾습니다.
- 짧은 문구가 넓은 영역 가운데 작게 남지 않도록 점유율이 낮으면 다시 확대합니다.
- 영역을 넘을 때 폰트 크기를 즉시 작게 만드는 대신 글자 가로폭과 세로높이를 우선 조절합니다.
- 자동 조판의 가로폭과 세로높이는 원래 비율의 70% 아래로 압축하지 않습니다.
- 70%로도 들어가지 않는 경우 다른 영역을 침범시키지 않고 해당 영역 안에서 잘라내어 그리드를 지킵니다.
- 모든 글자는 수동 위치를 지정하기 전까지 해당 영역의 세로 중앙에 고정됩니다.
- 좌·중앙·우 정렬은 문단 정렬 설정을 따릅니다.

4. 그리드 안정성
- 문구 편집이나 꾸미기 변경만으로 영역 위치와 크기가 바뀌지 않습니다.
- 자동 배치는 템플릿 적용 또는 ‘자동 배치 다시 실행’을 눌렀을 때만 다시 계산합니다.
- 수동 수정한 문장은 ‘수동 조정 초기화’를 누르기 전까지 자동 배치에서도 영역·위치·크기·꾸미기를 유지합니다.
- 수동으로 수정한 영역은 템플릿을 다시 적용하거나 영역 복귀를 누르기 전까지 다른 영역과 함께 재배치되지 않습니다.
- 사진·요소 클리핑은 지정 영역에만 적용하고 다른 영역의 텍스트 흐름을 바꾸지 않습니다.

5. 축소 렌더링 수정
- 글자 높이(scaleY)가 실제 미리보기와 저장 이미지에 반영되도록 렌더러를 수정했습니다.
- 여러 문장이 한 영역에 있을 때 폰트 크기를 일괄 축소하지 않고 세로높이를 70% 한도 안에서 조절합니다.
- 가로 공간이 부족할 때도 글자 폭을 70% 아래로 찌그러뜨리지 않습니다.

6. 기존 편집 기능 유지
- 실행취소·재실행
- 수치 슬라이더 + 직접 입력 + −/+ + 복귀
- 문장별 폰트·자간·행간·가로폭·세로높이·효과
- 프리텐다드 Variable 굵기
- KoPub 및 조선 폰트
- 색상 선택기와 주색/보조색 컬러칩
- 사진 정비율 확대·축소 및 투명 픽셀 트림
- 영역/텍스트/요소 선택 모드 분리
- PNG/JPG 저장
- 가로/세로 및 사용자 지정 mm 대지
- 라이트/다크 모드
- 미리보기 확대·축소·맞춤
