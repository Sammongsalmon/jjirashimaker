찌라시 메이커 v8

구성
- index.html
- styles.css
- app.js
- assets/fonts/PUT_KOPUB_FONTS_HERE.txt

설치
1. 위 파일과 assets 폴더를 GitHub 저장소에 올립니다.
2. 사용자가 보유한 KOPUB2.0_OTF_FONTS.zip을 저장소 최상위에 둔 뒤 Codespaces 터미널에서 실행합니다.

   mkdir -p assets/fonts
   unzip -j -o "KOPUB2.0_OTF_FONTS.zip" '*.otf' -d assets/fonts

3. 정적 웹서버 또는 GitHub Pages로 index.html을 엽니다.

CSS가 사용하는 폰트 파일명
- KoPub Dotum_Pro Medium.otf
- KoPub Dotum_Pro Bold.otf
- KoPub Batang_Pro Medium.otf
- KoPub Batang_Pro Bold.otf


v8 추가 변경 사항
- 상단에 실행취소/재실행 버튼을 추가했습니다. 단축키는 Ctrl/Cmd+Z, Ctrl+Y, Ctrl/Cmd+Shift+Z입니다.
- 문장 글자 크기는 선택 문장 아래에서 슬라이더, 숫자 입력, -/+ 버튼으로 모두 조절됩니다.
- 드래그와 슬라이더 조작은 연속 입력을 묶어 기록하도록 처리했습니다.
- 모바일 상단에서는 실행취소/재실행 버튼을 아이콘형으로 유지합니다.

v7 주요 변경 사항
- 레이아웃 템플릿 15종을 유지하면서 불필요한 띠와 가로선을 줄였습니다.
- 템플릿 이름을 입력 문구와 무관한 직관적인 레이아웃 이름으로 정리했습니다.
- 템플릿은 현재 주색·보조색 1·보조색 2를 따라 색이 생성되며, 템플릿을 바꿔도 팔레트는 유지됩니다.
- 전체 캔버스 띠와 글자 영역 내부 띠를 각각 추가할 수 있습니다.
- 영역 띠는 지정한 글자 영역의 좌우 끝까지 확장되고, 해당 영역 안에서 세로 위치를 조절합니다.
- 새 문장을 추가하거나 문장을 고치면 영역 크기와 남은 공간을 다시 계산해 크기·행간·자간·유니코드·문자 효과를 자동 조정합니다.
- 짧은 문장은 큰 글자, 입체·외곽선·유니코드 장식 등으로 강조될 수 있습니다.
- 문장별 자동 맞춤과 직접 꾸미기를 전환할 수 있으며, 세부 옵션은 선택한 문장 바로 아래에서 접고 펼칠 수 있습니다.
- 글자와 영역·도형에 두께가 쌓이는 입체 효과와 최종 투영 그림자를 추가했습니다.
- 영역과 요소는 한 번 눌러 선택만 하며, PC에서는 더블클릭, 모바일에서는 길게 눌러야 이동·크기·회전 핸들이 열립니다.
- 이분 선택 옵션은 가능한 경우 버튼형 선택기로 정리했습니다.

주요 조작
- 문장: 미리보기에서 바로 끌어 같은 영역 안에서 위치 조정
- 문장 교환: 다른 문장 위에 놓으면 두 문장의 자리를 교환
- 영역 이동: 빈 글자 영역에 놓으면 그 영역으로 이동하고 이후 자동 재배치에서 고정
- 영역·요소 선택: 한 번 클릭 또는 터치
- 영역·요소 편집 핸들: PC 더블클릭 / 모바일 길게 누르기
- 핸들 중앙 드래그: 이동
- 모서리 핸들 드래그: 크기 조절
- 위쪽 원형 핸들 드래그: 회전
- 영역선 체크: 편집용 글자 영역과 선택 상태 확인
- PNG/JPG 저장: 선택 표시와 안내선을 제외하고 재단여백까지 포함해 저장

띠 사용
- 전체 띠: 캔버스 전체 폭을 가로지릅니다.
- 영역 띠: 선택한 글자 영역의 폭 안에서만 좌우로 확장됩니다.
- 띠는 기본적으로 문장을 밀어내지 않으며, 필요하면 '피해서 배치'를 선택하고 회피 여백을 음수부터 양수까지 조절할 수 있습니다.

주의
- KoPub 폰트 파일은 이 배포 ZIP에 포함되어 있지 않습니다. 위 명령으로 사용자가 보유한 폰트를 직접 설치하세요.
- 브라우저에서 파일을 직접 열 때도 동작하지만, GitHub Pages 또는 정적 서버에서 실행하는 것을 권장합니다.
