기존 assets/fonts 폴더와 KoPub 폰트 파일은 그대로 두고, 위 파일만 저장소의 같은 위치에 덮어쓰면 됩니다.

v9 변경 사항
- 일반 그림자를 번짐 없는 평면 그림자로 변경했습니다.
  - 블러 0으로 처리하는 방식이 아니라, 동일한 실루엣을 한 번 평행 이동해 직접 그립니다.
  - 색상 혼합과 그라데이션을 사용하지 않습니다.
- 입체 효과를 단색 옆면 적층 방식으로 변경했습니다.
  - 깊이에 따른 명암 그라데이션이 없습니다.
  - 입체 효과 뒤에 별도의 그림자나 번짐을 넣지 않습니다.
- 모든 수치 옵션에 동일한 조작 방식을 적용했습니다.
  - 슬라이더
  - 직접 숫자 입력
  - − / + 버튼
  - '↺ 복귀' 버튼으로 해당 값 원상복귀
- 숫자 입력은 값을 지우는 중이거나 '-', '.', '0.' 같은 중간 입력을 허용합니다.
  - Enter 또는 포커스 해제: 범위와 간격에 맞춰 확정
  - Esc: 편집 전 값으로 취소
- 영역·요소 수치의 원상복귀 기준은 해당 템플릿 또는 요소가 만들어졌을 때의 값입니다.
- 문장 수치의 원상복귀 기준은 자동 맞춤에서 직접 꾸미기로 바꾸기 직전의 값입니다.
- 슬라이더·직접 입력·캔버스 드래그는 조작 한 번이 실행취소 한 단계가 되도록 묶었습니다.
- 실행취소/재실행 버튼과 Ctrl/Cmd+Z, Ctrl+Y, Ctrl/Cmd+Shift+Z를 유지합니다.

폰트 설치
사용자가 보유한 KOPUB2.0_OTF_FONTS.zip을 저장소 최상위에 둔 뒤 Codespaces 터미널에서 실행합니다.

mkdir -p assets/fonts
unzip -j -o "KOPUB2.0_OTF_FONTS.zip" '*.otf' -d assets/fonts

CSS가 사용하는 폰트 파일명
- KoPub Dotum_Pro Medium.otf
- KoPub Dotum_Pro Bold.otf
- KoPub Batang_Pro Medium.otf
- KoPub Batang_Pro Bold.otf

주의
- KoPub 폰트 파일은 교체용 ZIP에 포함되어 있지 않습니다.
- GitHub Pages 또는 정적 웹서버에서 실행하는 것을 권장합니다.


v9.1 추가 보완
- 재단여백을 포함한 모든 연속 수치 옵션을 슬라이더 + 직접 입력 + −/+ + 원상복귀 방식으로 통일했습니다.
- 직접 입력은 빈 값, 음수 기호, 소수점 같은 편집 중간 상태를 허용하고 Enter/포커스 해제에서 확정합니다. Escape는 편집 전 값으로 되돌립니다.
- 그림자는 동일한 실루엣을 한 번 옮겨 그리는 방식으로 번짐 없이 딱 떨어집니다.
- 단색 입체는 동일한 한 색을 1px 간격으로 쌓고 별도 그림자나 명암 그라데이션을 넣지 않습니다.
- 문장 입력창에서 바로 수치 버튼을 누를 때 첫 클릭이 자동 조판 재렌더에 사라지지 않도록 보완했습니다.
